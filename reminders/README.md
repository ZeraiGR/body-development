# 🦴 spine20 — напоминатель «правило 20-8» для macOS

Фоновое напоминание **каждые 20 минут** встать на 8 секунд — снять пиковое давление
в межпозвоночных дисках (~185% при сутулости → ~100% стоя), подышать животом и
потянуться. Реализует микро-действие из **Дня 1** курса.

Построен на **launchd** (нативный планировщик macOS) + **osascript** (встроенные
уведомления). Никаких внешних зависимостей и установок — только то, что уже есть
в macOS. Переживает перезагрузку, сон и выход из сна.

---

## Установка (одна команда)

```bash
cd ~/work/personal-projects/body-development/reminders
./spine20ctl.sh install
```

Готово. Напоминания пойдут каждые 20 минут и будут включаться сами при каждом
логине/перезагрузке Mac.

**Проверить, что нотификация вообще доходит** (первый раз может потребоваться
разрешение — см. ниже):

```bash
./spine20ctl.sh test
```

## ⚠️ Разрешение и стиль уведомления (один раз)

При первом срабатывании macOS может не показать нотификацию, пока ты не разрешишь.
И сразу выбери правильный стиль, иначе напоминание исчезнет за ~5 секунд.

1. Открой **Системные настройки → Уведомления** (System Settings → Notifications).
   (Быстро из терминала: `open "x-apple.systempreferences:com.apple.Notifications-Settings.extension"`.)
2. Найди в списке приложение-отправитель. Для `osascript` это
   **«Редактор скриптов»** (по-английски — Script Editor; bundle-id
   `com.apple.ScriptEditor2`). Может быть ниже в списке — прокрути.
3. Включи **«Разрешить уведомления»** (Allow Notifications).
4. **Стиль предупреждений → «Постоянно» (Persistent).** Не «Временно».
   На macOS 26 (Tahoe) прежние «Баннеры/Оповещения» переименовали:
   - **«Временно» (Temporary)** — исчезает за ~5 секунд (старый «Баннер»).
   - **«Постоянно» (Persistent)** — висит, пока не закроешь (старое «Оповещение/Alert»).
   На более старых macOS (Sonoma и ниже) выбирай **«Оповещения» (Alerts)** вместо «Баннеры».
   «Постоянно/Oповещения» — ровно то, что нужно, чтобы не проглядеть напоминание,
   но оно не крадёт фокус и не блокирует работу.

После этого запусти `./spine20ctl.sh test` ещё раз — нотификация должна появиться
и остаться на экране. Разрешение и стиль сохраняются насовсем.

## Управление

| Команда | Что делает |
|---|---|
| `./spine20ctl.sh install` | Установить и запустить (автозапуск при логине) |
| `./spine20ctl.sh uninstall` | Полностью удалить |
| `./spine20ctl.sh on` | Включить (после `off`) |
| `./spine20ctl.sh off` | Поставить на паузу |
| `./spine20ctl.sh status` | Работает ли сейчас |
| `./spine20ctl.sh test` | Отправить одну нотификацию сейчас |

**off vs uninstall:** `off` ставит на паузу, но агент поднимется снова при
перезагрузке. `uninstall` удаляет полностью.

## Как это работает и почему надёжно

- **launchd LaunchAgent** `~/Library/LaunchAgents/com.bodydev.spine20.plist`
  с `StartInterval = 1200` (20 минут). launchd — это системный планировщик macOS;
  LaunchAgent из `~/Library/LaunchAgents/` автоматически загружается при логине
  пользователя и переживает перезагрузку. Ничего не нужно добавлять в «Автозагруз»
  вручную — launchd сам подхватывает.
- **Сон:** пока Mac спит, таймер остановлен; при пробуждении launchd возобновляет
  отсчёт. Первое напоминание после пробуждения — в пределах ~20 минут от醒来.
  Это нормальное поведение для напоминаний и полностью покрывает «работает при
  выходе из сна».
- **osascript `display notification`** — встроенный механизм macOS, без внешних
  бинарников (terminal-notifier на Sequoia/Tahoe ненадёжен). Если `terminal-notifier`
  всё же установлен — используется он (лучший UX, игнорирует «Не беспокоить»).
- **Сообщения рандомизированы** (8 вариантов), чтобы напоминание не превратилось
  в фоновый шум, который мозг перестаёт замечать.

**Логи** (если что-то не работает): `/tmp/spine20.log` и `/tmp/spine20.err`.

## Если нотификации не приходят — чек-лист

1. **Разрешение:** Системные настройки → Уведомления → разрешить отправителю (см. выше).
2. **Не беспокоить / Фокус:** проверь, что не включён режим «Не беспокоить», который
   глушит уведомления. (`osascript` не умеет его игнорировать; `terminal-notifier`
   с `-ignoreDnD` — умеет, см. опциональную установку ниже.)
3. **Агент загружен?** `./spine20ctl.sh status` → должно быть «● работает».
4. **Скрипт не падает?** Посмотри `/tmp/spine20.err`.
5. **Ручной запуск:** `bash reminders/spine20-notify.sh` — если нотификация есть,
   проблема в launchd; если нет — в разрешениях.
6. **Переустановка:** `./spine20ctl.sh uninstall && ./spine20ctl.sh install`.

### Опционально: terminal-notifier (игнорирует «Не беспокоить»)

Если хочется, чтобы напоминание пробивалось даже через Focus/Не беспокоить:

```bash
brew install terminal-notifier
```

Скрипт автоматически подхватит его, если найдёт в `PATH`.
