# Бот реабилитации спины

Личный бот с каналами Telegram, VK и MAX (aiogram 3.x + APScheduler + SQLite).

> Техническая документация — в [personal-docs, раздел bots](https://github.com/ZeraiGR/personal-docs/tree/main/src/content/docs/bots).
> Здесь — краткий стартовый гайд.
Однопользовательский: доступ Telegram ограничен владельцем (`ALLOWED_CHAT_ID`).
Дополнительные платформы и LLM включаются отдельно; модель доступа проверяется тестами.

## Что делает

- **Утро**: завязка урока, одно посильное действие и кнопка «Читать здесь».
  Все 30 тем читаются в чате по коротким фрагментам, место чтения сохраняется.
- **Иллюстрации и видео**: шесть изображений с моделью человека; у каждой темы
  есть видео, автор, язык и подсказка для просмотра. Связанные темы используют
  одни материалы с разными акцентами. Русскоязычные ролики выбираются в первую очередь.
- **Днём**: короткое напоминание сменить положение.
- **Вечер**: боль 0–3 → движение (полностью / частично / нет) → чтение.
  Незаконченный опрос сохраняется, его можно продолжить в другом мессенджере.
  Готовую запись можно изменить отдельной кнопкой; повторные ответы не добавляют дни.
- **Отчёт**: семь календарных дат, отдельные записи самочувствия, движения и чтения.
  Пропуск отличается от нулевой боли, ранние оценки с неизвестной шкалой не входят
  в новое среднее. Чтение прошлого урока учитывается в дату чтения.

Актуальный курс — `data/articles/`. Стиль — `docs/EDITORIAL_STYLE.md`.
`MONTH_1_PLAN.md` и `YEARLY_PLAN.md` — исторические планы, не текущие назначения.
Учебный день не означает стадию восстановления и не подтверждает готовность к нагрузке.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.lock

cp .env.example .env
# заполни .env:
#   BOT_TOKEN        — токен от @BotFather
#   ALLOWED_CHAT_ID  — твой id (узнать у @userinfobot)
```

## Публикация и обновление Telegraph

```bash
python3 scripts/upload_telegraph.py
```

Создаёт новые страницы только для отсутствующих или изменившихся уроков, сохраняет
ссылки и хеши содержимого после каждой публикации. Повторный запуск продолжает работу.
Сначала проверяет доступность иллюстраций: файлы должны быть опубликованы в `main`.
Если `TELEGRAPH_TOKEN` пуст, создаёт аккаунт и сохраняет токен в приватном `.env`.

Пока новая страница не опубликована, бот предлагает полный урок внутри чата.
Ссылку на старую версию он не показывает; прежняя страница и запись в БД сохраняются.
Публикация — сетевое действие, отдельное от запуска и тестирования бота.

## Запуск

```bash
python3 main.py
```

Бот крутится long-polling, пока работает процесс. Напиши ему `/start`.

## Команды

| Команда    | Действие                                              |
|------------|-------------------------------------------------------|
| `/status`  | день, неделя, серия вечерних записей, пауза |
| `/today`   | показать утреннее сообщение текущего дня вручную      |
| `/evening` | начать или продолжить вечерний опрос |
| `/report`  | последние 7 календарных дней |
| `/report ГГГГ-ММ-ДД` | неделя, заканчивающаяся указанной датой |
| `/theory N`, `/goto N` | открыть урок без изменения дня программы |
| `/lessons` | все темы и прочитанное |
| `/continue N` | продолжить программу с дня N, сохранив историю |
| `/pause`   | `/resume` — пауза/снятие рассылок                     |
| `/next`    | перескочить на следующий день                         |
| `/hard`    | задержаться на неделе ещё на 2 дня                    |
| `/reset`   | вернуться к дню 1; чтение и записи сохраняются |

## Структура

```
config.py              env: токены, chat_id, таймзона, время рассылок, путь к БД
main.py                точка входа (polling)
bot/
  security.py          single-user guard + устойчивость к инъекциям
  db.py                SQLite: user_state / daily_logs / telegraph_links
  planner.py           перевод дня, недели, стадии, streak, sparkline
  messages.py          тексты, чтение по фрагментам, календарный отчёт
  journey.py           общая логика чтения и опроса для трёх мессенджеров
  handlers.py          команды + колбэки вечернего флоу
  scheduler.py         APScheduler: утро/пинг/вечер/воскресный отчёт
  telegraph.py         клиент Telegraph API
  content/
    articles.py        30 статей теории
    program.py         учебные недели и темы этапов
scripts/
  upload_telegraph.py  публикация новых и обновлённых статей
  preview_course.py    локальный HTML-предпросмотр всего курса
```

## Настройка расписания

Все тайминги — в `.env` (локальное время в `TIMEZONE`, по умолчанию `Europe/Moscow`):
`MORNING_TIME`, `EVENING_TIME`, `DAY_PING_START`, `DAY_PING_END`.

## Проверки и выпуск

```sh
.venv/bin/python -m unittest discover -s tests -v
```

GitHub Actions запускает проверки, но не выполняет SSH и не перезапускает production.
Выпуск бота — отдельное ручное действие после бэкапа и проверки интерпретатора systemd.
В `ops/` находится только drop-in бота; он не применяется автоматически.

Миграция добавляет историю чтения, черновики опроса, `pain_scale` и `habits_status`.
Она не пересчитывает старые оценки и не удаляет существующие записи. Перед выпуском
нужен согласованный снимок SQLite. Для отката к старому коду остановить бот и вернуть
снимок, если важно сохранить прежнюю интерпретацию полей `pain` и `habits_done`.

Предпросмотр без запуска бота и публикации:

```sh
.venv/bin/python scripts/preview_course.py --output /tmp/body-course-preview.html
```

В нём используются локальные иллюстрации, поэтому результат доступен до публикации
ветки. Источники и пределы проверки видео: [материалы курса](docs/COURSE_MEDIA.md).
